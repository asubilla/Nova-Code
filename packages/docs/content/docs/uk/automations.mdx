# Автоматизація

Автоматизація з'єднує тригери з багатокроковими workflows: webhook або подія проєкту запускає конвеєр промптів і shell-команд із правилами авто-sхвалення, бюджетами, повторами та чергою погоджень. Налаштуйте їх у **Налаштування → Nova Code → Автоматизація**.

## Тригери

Тригер — це те, що запускає workflow (або заплановане завдання). Два види:

- **Webhook** — HTTP POST ззовні Nova Code. Ви отримуєте URL і секрет; надсилайте секрет у заголовку `X-Webhook-Secret`. Зручно для CI, cron на іншій машині чи кнопки в іншому інструменті.
- **Подія** — те, що вже сталося тут: сесія завершилася, сесія зазнала помилки або збилося заплановане завдання.

Спрямуйте кожен тригер на один workflow (або заплановане завдання) і збережіть. **Fire** запускає тригер вручну, щоб перевірити зв'язки, перш ніж зовнішній викликач надішле запит.

## Workflows

Workflow — це упорядкований список кроків. Кожен крок або:

- **Prompt** — надіслати повідомлення до сесії (створити нову або використати наявний id), за потреби зачекати, доки сесія не стане неактивною.
- **Shell** — виконати команду в каталозі проєкту з часовим обмеженням.

Кожен крок має власну політику **у разі помилки**:

- **stop** (типово) — завершити запис і зафіксувати помилку
- **continue** — зафіксувати помилку й рухатися далі
- **retry** — повторити з експоненційним бек-офом за налаштуваннями workflow

Необов'язковий **бюджет** (`max tokens`, `max attempts`) чисто зупиняє запуск із `budget_exhausted` замість помилки на середині кроку. **Run** виконує workflow негайно; журнал аудиту фіксує кожен крок.

## Правила авто-sхвалення

Правила в розділі **Policy** визначають, що робити, коли агент просить дозвіл. Кожне правило зіставляється за шаблонами інструмента й вмісту (wildcards `*` і `?`). Перше ввімкнене правило, що збіглося, перемагає:

- **accept** — авто-sхвалити
- **deny** — відмовити (утримано й позначено як відмовлене)
- **hold** — залишити вам, занесено до черги погоджень

Політика автоматизації виконується перед зовнішньою мережею безпеки; перемагає перший ненульовий вердикт.

## Черга погоджень

Утримані дозволи потрапляють до черги погоджень. Погоджуйте або відмовляйте по одному чи позначте кілька й вирішіть партією. Кожне рішення відповідає OpenCode, тож очікуваний агент одразу продовжує (або зупиняється).

## Журнал аудиту

Кожен запуск додає запис: що спрацювало, результат кожного кроку, вердикти політики та ескалації. Записи лише додаються й обмежені, тож журнал ніколи не росте без меж. Невдалий запис аудиту фіксується як попередження й ніколи не валить запуск, який його породив.

## Майте на увазі

- Секрети webhook ніколи не залишають сервер і не показуються знову після збереження.
- Тригери та workflows спрацьовують лише поки запущений сервер Nova Code.
- Один поганий тригер чи workflow пропускається під час читання; він ніколи не блокує інші.
