# Agent Control Tool

Use the `novacode` agent tool to manage work in the app directly from chat. It is enabled by default when Nova Code runs its own local OpenCode server; there is no separate tool to install or shell command to run.

## What you can ask

Ask the agent in plain language. For example:

- "Create a new Nova Code session in this project, use the `openai/gpt-5.6-sol` model, and send it this prompt: review the authentication flow."
- "Create a new Nova Code session for this task in a separate worktree, and ask it to add tests for the login flow."
- "Use Nova Code to list my 10 most recent sessions and include their current status."
- "Create an Nova Code scheduled task named Weekday review that sends this prompt at 09:00 every weekday: review changes since the last run."
- "Run the Nova Code scheduled task named Weekday review now."
- "Check the Nova Code session named Authentication review and show me its latest assistant response."

The tool can list projects and model preferences, create and follow up on sessions, fork a session, create isolated worktree sessions, and manage scheduled tasks. Sessions started this way appear in Nova Code like any other session, so you can open them and continue the work yourself.

## Keep in mind

- New session prompts return immediately by default. Follow the session in Nova Code, or ask the agent to check it later.
- A separate worktree is only created when you ask for one. Uncommitted changes from your current worktree are not copied into it.
- The tool cannot delete sessions or worktrees, register project paths, run arbitrary shell commands, or call arbitrary URLs.

## Turn the tool on or off

Open **Settings → General → Nova Code Tools** and change **Agent control tool**. The setting applies once the managed OpenCode server restarts, which Nova Code offers as **Apply & Restart**.

The tool is not available when Nova Code connects to an external OpenCode server through `OPENCODE_HOST` or skip-start, or inside the VS Code extension. Desktop and web installations that use Nova Code's managed OpenCode server support it automatically.
