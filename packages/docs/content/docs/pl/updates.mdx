# Aktualizacje

Sposób aktualizacji Nova Code zależy od tego, jak go zainstalowałeś. W każdym przypadku możesz sprawdzić swoją bieżącą wersję w **Settings → Nova Code → About**.

## Aplikacja na komputerze

Aplikacja na komputerze sprawdza aktualizacje względem wydań na GitHub. Gdy jedna jest dostępna, Nova Code Cię informuje, pobiera ją, gdy zdecydujesz, i instaluje przy następnym restarcie. Zawsze masz kontrolę — nic nie instaluje się bez Twojej zgody.

## Wersja webowa / CLI

Jeśli zainstalowałeś CLI, zaktualizuj je z poziomu **About** za pomocą przycisków sprawdzania i aktualizacji albo z terminala:

```bash
nova update
```

Nova Code wykrywa, jak został zainstalowany (npm, pnpm, yarn lub bun), i uruchamia właściwą aktualizację za Ciebie.

## Serwer OpenCode

Nova Code i OpenCode aktualizują się osobno. Gdy dostępna jest nowa wersja OpenCode, Nova Code proponuje jej aktualizację i restartuje serwer po jej zakończeniu. Zobacz [OpenCode Server](/pl/opencode-server/), aby dowiedzieć się, jak ten serwer jest zarządzany.
